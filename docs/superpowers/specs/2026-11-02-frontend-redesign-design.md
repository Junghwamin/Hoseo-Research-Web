## 1. 의도

**왜 지금 구린가.** 세 가지가 겹친다.

1. **글꼴이 없었다.** Pretendard 를 쓴다고 적어 두고 파일을 넣지 않아 배포본이 맑은
   고딕으로 떴다. 표제가 커도 무게가 없던 이유다. (이 작업에서 먼저 번들했다 — §3.1.)
2. **도구 위에 랜딩을 얹었다.** 도서관 스톡 사진 + 어두운 스크림 + 3D 와이어프레임 +
   "Coming soon" 없는 모듈 탭 + 알약 스텝 + 카드 안의 카드. 2019년 템플릿의 신호다.
   390px 에서 첫 입력칸이 약 890px 아래, 주 버튼 「분석 불러오기」는 1,500px 아래다.
3. **말이 독자를 모른다.** "연구실적을 권역 기준으로 읽는다" 는 누구에게 하는 말인지가
   없다. 독자는 기획처·IR센터·평가 담당자이고, 총장이 묻는 질문은 하나다 —
   **"우리 대학은 몇 번째인가."**

**무엇으로 바꾸나.** 사진과 장식을 걷어내고 **활자와 숫자로 서는 편집 디자인**으로 간다.
크림색 지면, 세리프 표제(Hahmlet), 또렷한 본문(Pretendard), 강조색은 딱 하나(코발트).
첫 화면이 곧 1단계다. 2단계부터는 지표 타일이 KOSIS·교육부 보도자료의 문법(지표명 ·
기준시점 · 값 · 단위 · 전년대비)을 따른다. 신뢰는 사진이 아니라 **출처·범위·기준일**
한 줄이 만든다.

## 2. 스토리텔링

**한 문장.** 매년 8월 대학알리미에 공시되는 xlsx 한 장에서 '우리 대학이 몇 번째인지'를
뽑던 일을, 공시 11개년 전체·권역·비교군으로 넓혀 확인한 그대로 Word 로 만드는 도구.

**홈의 네 박자**(위에서 아래로):

| # | 블록 | 역할 | 문구 |
|---|---|---|---|
| 1 | 표제 | 질문을 던진다 | **우리 대학은 몇 번째인가** |
| 2 | 신뢰 띠 | 숫자의 출처·범위를 먼저 밝힌다 | 자료 대학알리미 「7-가. 전임교원의 연구 실적」 · 공시 2016–{latest}년 · {`dataset.nationalRankScopeNote` 원문: "전국순위는 대학알리미에 등재된 사립 {N}개교 기준이다. …"} · 매년 8월 말 공시 반영 |
| 3 | 1단계 | 바로 시작한다 | (마법사) |
| 4 | 쓰임 | 어디에 쓰는지 | 기관평가인증 자체진단보고서 「교원의 연구활동 및 성과」, 2년 주기 자체평가, 총장·보직자 보고의 근거표. 표 3개·차트 5장·서술 4절. |

부제: "전임교원 1인당 SCI급·SCOPUS 논문 수를 전국(사립 등재교)·권역·비교군 안에서
읽고, 확인한 그대로 Word 보고서로 만듭니다."

**말의 규율.**
- 숫자는 API 값만 쓴다. `134개교` 같은 상수를 박지 않는다(2016년 128, 2026년 133).
- 발명 금지: "N시간→N분", "업무 90% 단축", 고객 수, 추천사. 셀 수 있는 사실만
  (공시 11개년, 다단 헤더, 다캠퍼스 6개교 합산).
- 금지어: 혁신·스마트·AI 기반·원스톱·한눈에·손쉽게·최적화·Insight·Dashboard·KPI·이모지.
- `SCI/SCOPUS` → **`SCI급·SCOPUS`**(대학알리미 공식 표기). 첫 등장은 완전 표기
  "전임교원 1인당 SCI급·SCOPUS 논문 수", 표 머리글은 "1인당 논문(편)".
- 연도는 **"{year}년 공시"** 로 쓴다. 실적연도 병기("2025년 실적")는 core 가 원본의
  기준연도 열을 아직 내보내지 않으므로 이번 범위 밖(§9).
- 사용자 노출 문구: 라벨·제목은 **명사형**("주요 지표", "연도별 상세"), 설명·안내는
  **합쇼체**("비교군을 고르지 않으면 권역 상위권으로 정합니다"). 코드 주석·문서의
  해라체는 그대로 둔다.
- **테스트가 잠근 문구는 바꾸지 않는다**(§8). 그 문구들은 해라체라도 둔다.

## 3. 시각 체계

**두 종류의 화면.** 히어로·쓰임 띠·푸터는 **페이지**(편집 디자인: 큰 세리프 표제, 넉넉한
여백)이고, 마법사 안쪽은 **앱 스크린**(조용한 패널: 1px 선, 14px 라벨, 색은 데이터에만,
등장 애니메이션 없음)이다. 아래 규칙은 이 구분으로 읽는다. 세리프는 페이지와 단계 제목
까지만 내려오고, 표·카드·숫자에는 오지 않는다.

### 3.1 글꼴 (완료 — 저장소에 들어 있음)
- **본문·숫자·h3 이하: Pretendard Variable 1.3.9** (OFL). npm 패키지가 만든 동적 서브셋
  92조각을 **수정 없이** 둔다(Reserved Font Name 'Pretendard' 때문에 직접 서브셋하면 이름을
  바꿔야 한다). `web/public/fonts/pretendard-1.3.9/`. 이 앱의 글자는 약 25조각(~700KB).
  굵기는 400/500/600 셋.
- **h1·단계 h2 만: Hahmlet 650** (OFL, Reserved Font Name 선언 없음 — 가변→정적 인스턴스
  수정본에 원래 이름을 써도 된다). KS X 1001 2,350자 + 라틴 한 파일(190KB). 없는 글자는
  Pretendard 로 떨어진다(브라우저에서 확인). 세리프를 둘 곳은 이 둘뿐이다 — 카드 제목·표·
  지표에 세리프가 내려오면 "조용한 패널" 규칙이 깨진다.
- `web/public/fonts/fonts.css` 를 `index.html` 에서 `<link>` 로 받는다. 레이아웃 CSS
  예산(20KB)과 분리하되 **숨기지 않는다**: `check-bundle.mjs` 에 `fontCss` 예산(20KB)을
  따로 세고 출력한다.
- `fonts.css` 와 글꼴 파일은 **`scripts/build_fonts.py` 가 생성한다**(저장소에 들여온다 —
  `fetch_media.py` 를 대신하는 자리). 입력은 `npm pack pretendard@1.3.9` 와 google/fonts
  의 `Hahmlet[wght].ttf`(커밋 해시 고정), 도구는 fontTools. 아래 Fallback 선언도 이 생성기의
  머리 템플릿에 들어간다. 손으로 고치지 않는다.
- Malgun Gothic 폴백에 메트릭을 맞춘 `'Pretendard Fallback'` @font-face(`size-adjust:
  86.4%`, `ascent-override: 110.2%`, `descent-override: 27.9%`)를 둬 swap 때 한글 줄바꿈
  이동을 줄인다(실측 비율: Pretendard 한글 폭 0.864em / Malgun 1.0em).
- 숫자는 Pretendard 의 `tabular-nums`(tnum 보유 확인). 별도 숫자 글꼴 없음.
  `--font-numeric: var(--font-sans)` 로 정의해 깨져 있는 4개 파일의 참조를 살린다.
  `--font-mono` 는 번들하지 않고 `ui-monospace, Consolas, 'D2Coding', monospace`.

### 3.2 타입 스케일 (토큰)
페이지는 유동(clamp), 앱 스크린은 **고정 5단계**(12/14/16/24/30). 한글은 받침 때문에
표제 행간 1.15 아래로 내리지 않고, 본문은 1.55–1.6 이다.

| 토큰 | 용도 | 크기 | 글꼴 |
|---|---|---|---|
| `--text-display` | 홈 h1 (페이지) | clamp(40px → 72px), lh 1.15, ls -0.02em | Hahmlet 650 |
| `--text-title` | 단계 h2 | 24px 고정(390px 에서 22px), lh 1.3, ls -0.01em | Hahmlet 650 |
| `--text-heading` | 섹션·카드 h3 | 16px, lh 1.4, 600 | Pretendard |
| `--text-lead` | 히어로 부제·단계 설명 | 16px, lh 1.6 | Pretendard 400 |
| `--text-body` | 본문·표·컨트롤 | 14px, lh 1.55 (모바일 입력은 16px) | Pretendard 400 |
| `--text-meta` | 캡션·각주·축 라벨 | 12px, lh 1.5 — **대비 4.6:1 이상인 색으로만** | Pretendard 400 |
| `--text-kpi` | 지표 "답" 숫자 하나 | 30px, lh 1.1, ls -0.02em, tnum | Pretendard 600 |
| `--text-kpi-sub` | 나머지 지표 숫자 | 24px, lh 1.1, tnum | Pretendard 400 |
| `--text-eyebrow` | 삭제. 소문자 추적 라벨·`uppercase` 는 쓰지 않는다 | — | — |

제목에 `text-wrap: balance`, 본문에 `text-wrap: pretty`, `word-break: keep-all` 유지
(`overflow-wrap: anywhere` 는 삭제 — §5a). 굵기는 Hahmlet 650 하나, Pretendard
400/500/600 셋. 700 이상 쓰지 않는다. 컴포넌트는 이 토큰 유틸리티만 쓰고 `text-xs`·
`text-3xl` 같은 Tailwind 기본 크기를 직접 쓰지 않는다 — `tokens.test.ts` 에 정규식 검사
한 줄을 추가해 강제한다.

### 3.3 색 (토큰)
- **지면**: 웜 오프화이트 `#f7f5f0`(base) / `#ffffff`(raised) / `#efece6`(sunken).
  다크: `#141311` / `#1c1a17` / `#0f0e0c`. 순수 검정·흰색 지면 금지.
- **잉크**: `#15140f` / `#4a4740` / `#7a766d`. 다크: `#f2efe8` / `#b8b3a8` / `#8a857b`.
- **강조 하나: 코발트** `--accent #2f4ba8`(hover `#24398a`, soft `rgb(47 75 168 / .09)`),
  다크 `#8fa6ff`. 링크·선택·현재 단계·활성 데이터 계열에만. 딥그린은 뺀다 —
  "개선=초록" 의미색과 겹쳐 강조와 판정이 구분되지 않았다.
- **의미색**: up `#1f7a5f` / down `#b3261e` / neutral `#4a4740` (soft 는 10% 틴트).
  색만으로 구분하지 않는다 — 화살표·라벨 동반(기존 규약 유지).
- **주 행동 버튼**: 잉크색(`--action-bg #15140f`), 다크에서 반전. 알약 유지(버튼만).
- 그림자는 콤보박스 드롭다운 한 곳만(`--shadow-lg`). `--shadow-sm/md` 삭제. 카드는
  헤어라인(`--border-subtle #e3dfd6`)으로만. 다크 모드도 **선 하나**: 카드 배경을
  `--surface-base` 와 같게 두고 1px 선만 남긴다(밝기 단차 + 선 둘 다 쓰지 않는다).
- 그라데이션 0. 사진 0. 스크림 토큰(`--scrim-*`)·`--surface-overlay`(블러 상단바용) 삭제.
- 라이트 `--text-muted` 는 흰 바탕과 sunken 바탕 양쪽에서 4.6:1 이상이어야 한다(현재
  `#7a7a7a` 4.29:1 로 미달). 토큰 값을 정할 때 실측해 적는다.

### 3.4 간격·모서리·모션
- 간격 스케일 유지(4px 기반). 섹션 사이 `--spacing-9`(96px, 데스크톱) / `--spacing-7`
  (48px, 모바일). 컨테이너 `--container-content: 72rem` 유지, 5단계 본문은
  `--container-prose: 44rem`.
- 모서리: 버튼 알약, 입력 `--radius-md`(6px), 패널 `--radius-lg`(8px). 중첩 모서리는
  `inner = outer - gap`.
- 모션: `--duration-fast 120 / base 200 / slow 320ms`, `ease-out-quart` 유지. 스크롤
  리빌 없음. 움직이는 것은 상태 변화(단계 전환 포커스 이동, 버튼 busy, 펜딩 블록)뿐.
  `prefers-reduced-motion` 유지.

### 3.5 장식
- **장식 없음.** 표제·부제·신뢰 띠의 활자 위계가 곧 디자인이다. 홈에는 데이터가 아직
  없으므로(1단계 로드 전) 데이터 기반 장식도 만들지 않는다.
- 아이콘: 인라인 SVG 6개만(체크, 경고, 외부링크, 내려받기, 열기/닫기 셰브론, 테마).
  Lucide 경로를 복사해 `design/ui/Icon.tsx` 한 파일에 둔다(ISC). 아이콘 패키지 금지.
- 3D(`HomeHero/scene.ts`·`capability.ts`, three.js)·`MediaBand`·스톡 사진 2장·
  `fetch_media.py`·`web/public/media/` 삭제. 지연 청크 127KB 가 사라진다. `HomeHero` 는
  정적 컴포넌트가 되며 `hero-static` testid(aria-hidden 장식 레이어)는 유지한다.

## 4. 페이지 구성

```

────────────────────────────────────────────────────────────────────────────
Hero(활자만, 상하 64/40px)
  (meta) 기획처·IR센터·평가 담당자를 위한

  (lead) 전임교원 1인당 SCI급·SCOPUS 논문 수를 … Word 보고서로 만듭니다.
  [분석 시작]  ← <768px 에서만 렌더. 누르면 1단계 대학 입력칸으로 스크롤+포커스.
```

- **히어로는 stats 로드 후에도 남긴다**(언마운트하지 않음). 대신 2단계부터는 스크롤 위로
  올라가 보이지 않고, ContextBar 가 sticky 로 맥락을 대신한다. e2e 의 초기 로드 검사
  (`hero-static`)와 충돌하지 않는다.
- 모듈 탭(`module-research` 등) 은 **신뢰 띠 바로 아래 한 줄**로 유지한다(e2e 가
  `module-research` 가시성과 `module-educationCost` 부재를 검사한다). 꺼진 모듈은
  렌더하지 않는 규칙 그대로.

### 2단계 통계 확인
- 지표 4개를 카드 4장이 아니라 **헤어라인으로 나뉜 띠 하나**(`divide-x`, 모바일 2열)로.
  각 칸은 KOSIS 문법: 라벨(14px 회색) → 값 → 단위(작은 회색 접미) → 기준시점 "{year}년
  공시" → 전년대비 한 줄. **"답"은 하나다**: 전국순위만 `--text-kpi`(30px/600), 나머지
  셋은 `--text-kpi-sub`(24px/400). 표제의 질문("몇 번째인가")에 이 칸이 답한다.
- 전년대비는 알약 배지가 아니라 14px 문장("전년 대비 +6계단")이고 **색은 숫자에만**.
  0·null 은 회색. `metric-delta` testid·`data-direction`·▲▼·sr 라벨 계약 유지.
- `null` 값: `—` 를 **자기 노드로** 14px 회색으로 그린다(큰 대시는 로딩처럼 읽힌다;
  `getByText('—')` 정확 일치 계약 때문에 같은 노드에 다른 글자를 붙이지 않는다). 형제
  `sr-only` 노드에 "자료 없음".
- "전국순위" 라벨은 그대로. 캡션은 "{year}년 공시 · 사립 등재교 기준" 이고, `year` 가
  최신 연도일 때만 "· {universityCount}개교" 를 붙인다 — API 는 최신 연도 모집단 수만
  주므로 다른 해의 N 을 지어내지 않는다. `dataset.nationalRankScopeNote` 원문은 띠 바로
  아래 캡션(현재는 페이지 맨 아래)에도 둔다. 그림자·호버 리프트 제거.
- 표: 캡션 위에 "자료기준일 {year}년 8월 공시 · 단위 편·명". 기준 연도 행 강조 유지.
- 각주 한 줄: "논문 수는 대학알리미 집계 방식에 따른 환산 편수입니다(소수 포함).

## 5a. 감사에서 나온 결함 — 리디자인이 함께 고친다

실제 화면 캡처(1440·390 × 라이트·다크, 36장)로 확인한 것이다. 디자인이 아니라 버그라
테스트를 먼저 쓴다.

1. **모바일 글자 쪼개짐.** `tokens.css` body 의 `overflow-wrap: anywhere` 때문에 390px
   에서 2단계 연도별 표의 모든 셀('2016년' → 2/0/1/6/년)과 상단바 버튼('다/크',
   '시스/템', '설/정')이 글자 한 자씩 세로로 접힌다. `anywhere` 를 지우고
   `word-break: keep-all` 만 둔다. YearTable 에 `min-w-[48rem]` + 숫자 셀
   `whitespace-nowrap` + `role=region tabIndex=0`(CompareTable 과 같은 수준).
   Button 공통 클래스에 `whitespace-nowrap`. 잠금 테스트: 표 셀 `scrollHeight` 가
   한 줄 높이인지, 또는 e2e 모바일에서 `year-table` 행 높이 상한.
2. **+970.0%.** `Step2Metrics.rateLabel` 이 이미 퍼센트인 `changeRate`(API 확인: 9.7)에
   100 을 곱한다. 3단계는 같은 값을 +9.7% 로 보인다. `YoYPanel/transform.describeChange`
   를 재사용해 한 곳에서 라벨·방향·sr 라벨을 만든다. 잠금 테스트는 **`Step2Metrics` 렌더
   테스트**(`features/` 첫 테스트)에 둔다 — MetricCard 는 `delta.label` 을 받기만 하므로
   거기서는 잠글 수 없다. `changeRate: 9.7` 인 stats 로 렌더해 `+9.7%` 를 단언한다.
3. **`--font-numeric` 미정의.** 4개 파일이 참조하는데 토큰이 없다 → `var(--font-sans)` 로
   정의. `tokens.test.ts` 에 "소스가 참조하는 `var(--x)` 는 tokens.css 에 선언돼 있어야
   한다" 검사를 추가해 재발을 막는다.
4. **대비 미달.** 라이트 `--text-muted #7a7a7a` 는 흰 바탕 4.29:1, 푸터 바탕 3.9:1 로
   보조 문구 전부 AA 미달. 새 잉크 토큰(`#7a766d` → 실측 후 ≥4.6:1 되도록 `#6f6b62`
   수준으로 조정)으로 해결 — `--text-meta` 12px 는 4.6:1 이상인 색으로만 쓴다. recharts
   보조선에 `--border-strong`(1.5:1) 금지.
5. **서버 차트가 너무 작다.** 2열 그리드에서 1785px 원본이 493px 로 줄어 축 글자를 못
   읽는다. §5 3단계의 1열(추이·순위)·2열(나머지) 배치와 `aspect-ratio` 예약으로 해결.
   다크 모드에서 흰 PNG 는 `--color-ink-0` 매트(`p-3`, radius)로 감싸 "문서 미리보기"
   로 읽히게 한다. 서버 다크 렌더는 범위 밖.
6. **주 행동 버튼 둘.** 1단계 로드 후 검은 알약이 「분석 불러오기」와 「다음」 둘이다.
   stats 가 있으면 「분석 불러오기」를 secondary 「다시 불러오기」로 강등한다.
   (`load-button` testid·disabled 규칙 유지.)
7. **설정·데이터 갱신 패널이 본문을 밀어낸다.** 네이티브 `<dialog>` 모달로 바꾼다.
   `settings-toggle`/`data-update-toggle` 의 `aria-expanded`·`aria-controls`, 패널
   안 testid 전부 유지. 파일 입력은 `<label>` 드롭존 + 실제 `<input>`(testid·aria-label
   그대로).

## 5b. 조사가 바꾼 것, 바꾸지 못한 것

여섯 갈래 조사(디자인 규칙집 3종·2026 사이트 22곳 실측·청중·도구 패턴·글꼴·현재 화면
감사)에서 받아들인 것과 거절한 것을 적어 둔다. 다음 사람이 같은 논쟁을 반복하지 않도록.

**받아들임**
- 페이지/앱 스크린 이분법(§3 머리). 세리프를 h1·h2 로 제한한 이유다.
- 마법사 안 고정 타입 스케일, KPI "답 하나" 규칙, 델타는 숫자에만 색, null 은 작게.

- 웜 뉴트럴 지면(Anthropic `#faf9f5`, Cursor `#f7f7f4` 계열) — 순백·순회색은 거대한

- Vercel 캐시 헤더(`/assets/*`·`/fonts/*` immutable — 지금은 해시 자산까지 `max-age=0`),

**거절**

- 데이터 기반 히어로 장식(연도별 전국 평균 폴리라인). API 변경이 따르고, 활자만으로

  캠퍼스 금지" 규칙 위반이기도 했다).
- elaya 규칙 중 Geist/Manrope, 히어로 텍스트 그라데이션, 태그라인 단어별 리빌, 스크롤

## 11. 빌더 검토 후 결정 (작성자의 결정)

독립 검토자가 계획 전에 답이 필요하다고 한 질문 8개. 사용자가 결정을 위임했으므로
작성자가 정했다.

1. **1단계 이름** — `STEPS` 그대로 "데이터 설정". 스트립·h2·다음 버튼이 한 변수를 쓴다.
2. **V14 문구** — 신뢰 띠가 `dataset.nationalRankScopeNote` 원문을 그대로 보인다(e2e 가
   첫 로드에 `/등재된 사립 \d+개교 기준/` 을 요구). 손으로 쓴 같은 뜻의 문장은 두지 않는다
   — 한 사실은 한 변수. 그러려면 `useDataset` 이 App 수준으로 올라가 Hero 와 WizardShell
   이 같은 `dataset` 을 받는다(`dataVersion` 리마운트와 함께 묶는다).
3. **첫 화면 검은 알약** — 「분석 시작」은 <768px 에서만 렌더한다. 데스크톱은 폼이 첫
   화면이라 「분석 불러오기」가 유일한 primary. stats 가 생기면 그것도 secondary 로 내려가
   「다음」이 유일한 primary 가 된다. 어느 뷰포트·상태에서도 검은 알약은 하나다.
4. **전국순위 N** — 최신 연도일 때만 `universityCount` 를 붙인다. 다른 해의 수는 API 에
   없으므로 쓰지 않는다. API 변경은 비목표 유지.
5. **fonts.css** — 생성기 `scripts/build_fonts.py` 를 저장소에 넣는다. Fallback 선언도 그
   템플릿에서 나온다. 손편집 금지 주석은 그대로 참이 된다.
6. **MetricCard null** — `—` 한 노드(14px 회색) + 형제 `sr-only` "자료 없음".
7. **차트 렌더 부하** — 3단계 trend PNG 는 넣고(검토 무결성), 5단계 썸네일은 텍스트 목록으로.
8. **390px 목표** — "첫 화면에 시작 버튼" 으로 고친다(§6). 입력칸까지 끌어올리려면 신뢰
   띠·모듈 탭을 접어야 하는데 모듈 탭은 e2e 가 가시성을 요구하고, 신뢰 띠는 이 페이지의
   핵심 주장이라 접지 않는다.

검토자가 짚은 문서 오류(§5 의 15px·13px·h3 세리프 잔재, NOTICE "추가한다", §1 "글꼴이
없다" 현재형, +970% 잠금 위치)는 본문에서 고쳤다. **§3 이 §5 보다 우선한다.**
