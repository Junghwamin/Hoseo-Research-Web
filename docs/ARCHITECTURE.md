# 구조 — 무엇을 어디에 두는가

이 문서의 목적은 하나다. **새 기능을 붙일 때 어디를 열어야 하는지, 그리고
어디를 열지 않아도 되는지**를 정한다.

규칙은 문서에만 두면 지켜지지 않는다. 그래서 여기 적힌 것은 전부
`web/src/architecture.test.ts` 가 소스를 스캔해 강제한다. 어기면 테스트가
파일:줄까지 짚어 준다.

---

## 의존 방향은 한 방향이다

```
features/   화면 조립 — 단계·흐름·서버 호출
    ↓
components/ 도메인 컴포넌트 — 대학·권역·비교군을 아는 것들
    ↓
design/     디자인 시스템 — 도메인을 모르는 것들 (Button, Card, Field, 토큰)
```

거꾸로 가는 화살표는 없다.

- `components/` 가 `features/` 를 가져오면 그 컴포넌트는 그 화면에서만 쓸 수
  있게 된다.
- `design/` 이 `api/`·`store/` 를 가져오면 다른 앱에 붙일 수 없게 된다.

서버 쪽도 같은 규칙이다.

```
web/  →  api/  →  core/
```

`core/` 는 UI 프레임워크를 모른다(streamlit·fastapi 참조 0건). `api/` 는
`core/` 를 감싸기만 하고 계산을 다시 하지 않는다. `web/` 은 서버가 준 숫자를
그리기만 하고 통계를 다시 계산하지 않는다.

---

## 폴더 하나 = 독립 단위

```
components/Combobox/
├── Combobox.tsx          ← 컴포넌트
├── Combobox.test.tsx     ← 이 폴더의 테스트
├── filter.ts             ← 렌더 없이 검사해야 하는 순수 로직
└── index.ts              ← 공개 면(public surface)
```

**바깥에서는 `index.ts` 만 가져온다.**

```ts
import { Combobox } from '../../components/Combobox'          // 좋다
import { Combobox } from '../../components/Combobox/Combobox'  // 안 된다
```

내부 파일을 직접 가리키면, 파일을 쪼개거나 이름을 바꾸는 순간 호출부가 전부
깨진다. 배럴이 있으면 폴더 안쪽은 자유롭게 정리할 수 있다.

### 예외가 하나 있다

`components/HomeHero/index.ts` 는 `./scene`(three.js)을 **일부러 내보내지
않는다.** 배럴이 내보내면 3D 를 쓰지 않는 화면의 초기 번들에도 three.js 가
딸려 들어가, 지연 로딩 계약이 조용히 깨진다. `HomeHero` 가 실행 중에
`import()` 로만 부른다.

## 컴포넌트를 새로 만들 때

폴더 하나를 만들고 아래 순서를 밟는다(계획 §7.1).

| # | 단계 | 게이트 |
|---|---|---|
| 1 | props 타입 선언 | 무엇을 받고 무엇을 그리는지 확정 |
| 2 | **실패하는 테스트 먼저** | 정상 + 경계(빈 배열, `null`, 0, 긴 한글 이름) |
| 3 | 테스트가 통과할 만큼만 구현 | 토큰 외 하드코딩 값 0개 |
| 4 | Storybook 스토리 | 라이트/다크 × 모바일/데스크톱 |
| 5 | `vitest-axe` | 위반 0건 |
| 6 | `index.ts` 작성 | 공개할 것만 내보낸다 |

**테스트를 느슨하게 고쳐서 통과시키는 것은 실패로 친다.**

## 마법사 단계를 추가할 때

단계는 `features/wizard/steps/registry.ts` **한 곳에서만** 정의된다. 진행
표시, 이동 버튼, 잠금 규칙, 화면 제목이 전부 그 배열에서 파생된다.

1. `features/wizard/steps/Step6Something.tsx` 를 만든다 — `StepProps` 만 받는다
2. `registry.ts` 에 항목 하나를 넣는다
3. `store/types.ts` 의 `STEPS` 에 이름을 넣고 `Step` 유니온을 늘린다

그 외에 손댈 곳이 없다. `WizardShell` 은 단계에 대해 아무것도 모른다.

**단계 컴포넌트는 형제를 모른다.** 옆 단계를 직접 부르기 시작하면 순서를
바꿀 수 없게 된다 — 이것도 테스트가 막는다.

```ts
{
  id: 6,
  title: '내보내기',
  eyebrow: '6단계',
  description: '무엇을 하는 단계인지 한 줄.',
  Component: Step6Something,
  // 넘어갈 수 없으면 **이유를 문자열로** 돌려준다.
  // false 를 돌려주면 회색으로 죽어 있는데 왜인지 알 수 없는 버튼이 된다.
  blockedReason: (s) => (s.stats ? null : '먼저 분석을 불러와야 한다'),
}
```

## 상태

마법사 상태의 **모든 전이는 `store/reducer.ts` 하나를 지난다.**

원본 Streamlit 판의 확정 결함 6건(V04·V05·V06·V07·V17·V19)은 전부 "상태를
바꾸는 길이 여러 개였고 서로 어긋났다" 는 한 원인에서 나왔다. 길이 하나면
어긋날 수 없다.

- 리셋은 키를 골라 지우는 것이 아니라 **초기 상태를 새로 만드는 것**이다.
- 무엇을 남길지 고르지 않고 **무엇을 버릴지** 한 곳에 적는다(`clearDerived`).
- 폼 초안은 스토어에 넣지 않는다. `Step1Target` 의 지역 상태로 들고 있다가
  "불러오기" 에서 한 번에 확정한다.

### 입력과 출력을 헷갈리지 말 것

| 필드 | 방향 | 뜻 |
|---|---|---|
| `regionChoice` | 입력 | 다캠퍼스 대학에서 사용자가 고른 권역. `null` = 서버가 판정 |
| `regionName` | **출력** | 서버가 확정해 돌려준 권역. **화면에 쓰는 값은 언제나 이쪽** |
| `compareGroup`(선택 시) | 입력 | 사용자가 고른 비교군. `null` = 서버 기본값 |
| `compareGroup`(응답 후) | 출력 | 서버가 확정한 비교군. 차트 요청이 이 값을 쓴다 |

클라이언트가 권역을 추측하면 '권역평균' 이 엉뚱한 모집단을 가리킨다(V03).

## 디자인 값

색·간격·radius·shadow 는 `web/src/design/tokens.css` **밖에 존재하지 않는다.**
컴포넌트에 hex 나 `rgb()` 를 직접 쓰면 `design/tokens.test.ts` 가 잡는다.

테마 토큰 블록이 셋인 것은 CSS 의 제약이다 — 선택자 목록에 `@media` 를 넣을
수 없다. 세 블록의 토큰 이름과 값이 일치하는지도 테스트가 검사한다. 어긋나면
**테마를 고르지 않은 시스템 다크 사용자만** 조용히 깨진다.

색이 둘로 나뉘어 있다.

- `--action-*`: **누르는 것**. 검은 알약 버튼. 한 화면에 하나.
- `--accent`: **가리키는 것**. 링크·선택·현재 단계.

## 차트가 두 종류인 이유

| | 무엇 | 왜 |
|---|---|---|
| 서버 PNG | matplotlib, `/api/chart/{kind}.png` | **Word 에 들어가는 것과 같은 그림**이어야 한다 |
| 화면 차트 | recharts, 추이 하나만 | 값을 짚어 읽는 용도 |

화면을 전부 recharts 로 그리면 사용자가 확인한 그림과 문서에 실리는 그림이
갈라진다 — 확인 단계의 의미가 없어진다. 그래서 3단계의 나머지 4종은 서버
PNG 가 유일한 표현이고, 차트 요청에 **비교군을 반드시 함께 보낸다.**

## 미디어

`web/public/media/` 의 파일은 `scripts/fetch_media.py` 가 받아 둔 것이다.

- **CC0 만 쓴다.** 표시 의무가 있는 라이선스는 화면 어딘가에 크레딧을 계속
  달고 다녀야 하는데, 그 의무를 사람이 기억해야 하는 순간 언젠가 빠진다.
- **CDN 주소를 쓰지 않는다.** 설치본은 오프라인이라 사진이 통째로 빈다.
- **특정 대학 캠퍼스 사진은 쓰지 않는다.** 호서대 포털에 다른 대학 건물
  사진을 깔면 소속을 오해시킨다.

출처는 `web/public/media/CREDITS.md` 에 스크립트가 기록한다.

## 기능 플래그

`web/src/features.ts` 가 꺼 둔 것은 **렌더 트리에 올라가지 않는다.**
`disabled` 로 흐리게 보여주지 않는다 — Streamlit 판에서 홈 카드 2/3, 사이드바
모듈 절반이 "Coming Soon" 장식이었고, 그게 사용자가 "불편하다" 고 한 실체다.
